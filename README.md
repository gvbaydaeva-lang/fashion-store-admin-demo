# Демо-страница заказов

Самостоятельная статическая страница с вымышленными заказами для показа интерфейса обработки. Это не рабочая админка и не содержит реальных данных.

Демо-версия. Данные тестовые и не отправляются на сервер.

Статусы хранятся только в браузере посетителя. После обновления страницы они обычно сохраняются, но не передаются другим посетителям.

## Локальная проверка

```bash
npm test
npm run audit:demo
python3 -m http.server 4173 --directory site
```

Последняя команда открывает локальную копию по адресу `http://127.0.0.1:4173/`.

## Публикация

Workflow GitHub Pages запускает тесты и проверку доставляемых файлов, затем публикует только содержимое папки `site/`.
